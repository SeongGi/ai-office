# 03 계획

커밋 단위와 각 단계의 검증 명령. 테스트는 셸의 `AGENT_FLOOR_*` 값을 뺀 채로 돌린다.
`T="env -u AGENT_FLOOR_URL -u AGENT_FLOOR_TOKEN -u AGENT_FLOOR_DEVICE"`

1. 훅과 seed가 세션 제목을 이름으로 쓴다 (`adapters/transcript.mjs`, `adapters/claude.mjs`, `adapters/seed.mjs`, 테스트). 검증: `$T node --test test/*.test.mjs`
2. `rename` 이벤트와 `/rename` 길, 이름 저장 파일 (`shared/protocol.*`, `server/index.mjs`, `docs/protocol.md`, 테스트). 검증: 같은 명령
3. 카드에서 이름 고치기, "하는 일" 중복 제거, 퇴사 안내 문구 (`src/ui/hud.ts`, `src/ui/labels.ts`, `src/core/connection.ts`, `src/styles.css`). 검증: `$T npx tsc --noEmit`, `$T npm run build`, 테스트
4. 배포와 화면 확인: `docker compose up -d --build app`, 브라우저에서 이름 표시와 고치기 확인
