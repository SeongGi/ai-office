# 01 요구사항: 직원 이름을 세션 제목으로, 그리고 직접 고치기

## 목표

- 화면의 직원 이름이 늘 "Claude"로만 나와서 어떤 일을 하는 세션인지 알 수 없다. 이름을 세션 제목으로 보여 준다.
- 제목이 마음에 들지 않으면 관리자가 카드에서 이름을 직접 고칠 수 있게 한다.
- 함께 고치는 것 두 가지
  - 카드의 "하는 일"에 같은 글이 두 줄로 나온다. 같은 글이면 한 번만 보여 준다.
  - 퇴사 버튼 아래 안내가 "화면에서만 퇴사 처리돼요. 세션은 그대로예요."인데 실제로는 세션을 닫는다. 안내를 실제 동작에 맞춘다.

## 현재 동작 (확인한 사실)

- seed는 세션 기록(jsonl)의 `aiTitle`을 이름으로 쓴다(14자 넘으면 자른다).
- 실시간 훅(`adapters/claude.mjs`)은 늘 이름을 `Claude`로 보낸다. 서버는 기본 이름이 구체적인 이름을 덮지 않게 막지만, seed 없이 새로 시작한 세션은 끝까지 `Claude`로 남는다.
- 세션 기록에는 `{"type":"ai-title","aiTitle":...}` 줄이 계속 덧붙는다. `/rename`으로 붙인 제목은 `customTitle` 필드로 남는다(이 서버기기 기록에는 아직 없다).

## 하지 않을 것

- 서브에이전트 이름은 바꾸지 않는다(지금처럼 종류 이름).
- Codex와 Cursor 어댑터는 건드리지 않는다.
- 세션 기록 파일을 고치지 않는다(Claude Code의 `/rename`과 연동하지 않는다).

## 성공 기준

1. 훅만 쓰는 새 세션도 기록에 제목이 생기면 다음 훅부터 그 제목이 이름이 된다. `customTitle`이 있으면 그것이 `aiTitle`보다 앞선다.
2. 관리자는 카드에서 이름을 고칠 수 있고, 고친 이름은 훅이 보내는 제목보다 앞선다. 서버를 다시 띄워도 남는다.
3. 이름을 비워 저장하면 고친 이름이 지워지고 세션 제목으로 돌아간다.
4. 관리자가 아니면 이름 고치기 버튼이 보이지 않고 서버도 403을 준다. 시도는 감사 기록에 남는다.
5. "하는 일"에 같은 글이 두 번 나오지 않는다.
6. 기존 테스트 39개가 그대로 통과하고, 새 동작마다 테스트가 있다.

## 운영 위험

- 훅마다 세션 기록 끝 64KB를 읽는다. 이미 Stop 훅이 같은 일을 하고 있어 부담은 작지만, 읽기 실패는 조용히 넘어가야 한다.
- 이름 저장 파일이 커지지 않게 개수를 제한한다.
- 이름은 화면에 그대로 나오므로 길이를 제한하고 HTML은 지금처럼 이스케이프한다.

## 열린 질문

- 이름표가 길면 화면이 지저분해진다. 훅 제목은 seed와 같이 14자로 자른다. 직접 고친 이름은 성기님이 고른 것이므로 서버 제한(40자)까지 둔다.
