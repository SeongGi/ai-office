## 1. 리뷰 반영 확인

세 가지 모두 `desktop/installer.cjs`에 반영했고, 각각 테스트를 추가했다.

1. **`uninstallApp`에 darwin 가드 추가**: `installApp`과 동일하게 함수 맨 앞에
   `if (process.platform !== 'darwin') return { ok: false, error: NOT_DARWIN_ERROR };`를 넣었다.
   테스트 `uninstallApp: darwin이 아니면 바로 멈춘다(installApp과 동일한 가드)`가
   `process.platform`을 `linux`로 바꿔 넣고 에러와 "건드리지 않음"을 확인한다.
2. **성공 경로에서 tmpRoot 정리**: `movedOut` 플래그를 없애고, `finally` 블록이
   `tmpRoot`가 있으면(성공이든 실패든) 항상 `rmSync(tmpRoot, { recursive: true, force: true })`를
   부르도록 고쳤다(이미 옮겨진 `tmpApp` 경로는 `force: true`라 무해). 테스트
   `installApp: 성공 후 tmpRoot 전체(icon.iconset 포함)가 더 이상 존재하지 않는다`가
   가짜 fs의 `existsPaths`에서 `tmpRoot` 및 그 하위 경로가 전부 사라졌는지 확인한다.
3. **`pkg.version`이 문자열이 아니면 에러로 멈춤**: `package.json`을 읽은 직후
   `typeof pkg.version !== 'string'`이면 `{ ok: false, error: '...version...' }`으로 멈추고
   아이콘 생성 등 이후 단계를 건너뛴다. 테스트
   `installApp: package.json의 version이 문자열이 아니면 설치를 멈춘다`가
   `version: undefined`(JSON.stringify로 직렬화되면 키 자체가 사라짐)인 package.json을 주입해 확인한다.
4. **(여유 항목) 재설치 end-to-end 테스트 추가**: `installApp: 이미 설치된(우리 앱) 상태에서
   다시 설치하면 덮어써진다(재설치)`가 같은 가짜 fs로 `installApp`을 두 번 불러 두 번째도
   성공하고, 두 tmpRoot 모두 깨끗이 정리됐는지 확인한다.
