# 03 계획: 데스크톱 앱 설치형 만들기

작업 공간: `/Users/seonggi/Desktop/PDS/dev/ai-office-wt/desktop-installer` (브랜치 `feat/desktop-installer`). `01-요구사항.md`, `02-설계.md`(검토 반영 포함)를 전제로 한다.

## 커밋 단위

1. **`desktop/installer.cjs` + 단위 테스트**
   - `desktop/installer.cjs`: 설계대로 `installApp()`/`uninstallApp()`과 순수 함수(`resolveTemplateApp`, `iconsetFiles`, `buildAppStubSource`, `isOurApp`, `plistEdits`)를 구현한다. `installApp`/`uninstallApp`은 `{ run = spawnSync, fs: fsImpl = fs } = {}`로 외부 명령·파일시스템을 주입받게 한다(설계 검토 반영 6번).
   - `test/desktop-installer.test.mjs`: 순수 함수 테스트 + 가짜 `run`/임시 디렉터리로 `installApp`/`uninstallApp`의 단계 순서·에러 롤백·식별자 보호를 검사한다.
   - 검증: `env -u AGENT_FLOOR_URL -u AGENT_FLOOR_TOKEN -u AGENT_FLOOR_DEVICE -u AI_OFFICE_URL -u AI_OFFICE_TOKEN -u AI_OFFICE_DEVICE node --test --import ./test/support/clean-env.mjs test/desktop-installer.test.mjs`
2. **`bin/ai-office.mjs` + `package.json` 연결**
   - `commands`에 `'install-app'` 추가, `--uninstall` 플래그 분기, 도움말 한 줄.
   - `package.json`의 `scripts`에 `"install-app"` 추가.
   - 검증: 같은 전체 테스트 스위트(`npm test`)가 그대로 통과하는지(기존 199개 깨지지 않는지).
3. **README 갱신**
   - "Ways to run" 아래 "데스크톱 앱을 설치형으로 쓰기" 소절: 설치 순서, 지우는 법, iCloud 경고, 단일 인스턴스 잠금 공유 안내, Electron Helper 리네임 안 함, `xattr -cr` 안내.
   - 검증: 사람이 읽어서 순서대로 따라 할 수 있는지 확인(자동 검증 없음).

세 커밋 모두 끝난 뒤 전체 `npm test`와 수동 설치 검증(04-검증.md)을 한 번에 돌린다.

## 완료 기준

`01-요구사항.md`의 성공 기준 1~9번. 특히: `npm test` 전체 통과, 새 테스트가 의도적으로 깨뜨렸을 때 실제로 실패하는지 확인(원복), 이 컴퓨터에서 실제 설치·삭제 수동 확인.
