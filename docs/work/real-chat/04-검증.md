## 화면 확인

- 데모 빌드(pages)가 정상으로 뜨고, 고양이와 기존 데모 대화가 보인다.
- 데모에서는 실제 메시지가 자주 오가서, 설계대로 지어낸 책상 대화가 쉰다. 그래서 지어낸 대화가 화면에 뜨는 것은 아직 확인하지 못했다.

1. 로컬 서버(운영 서버 말고 다른 포트)에 `emit`으로 같은 팀 고양이 둘과, 오래 쉬는 고양이 둘을 올린다. 그다음 책상 대화와 쉬는 방 대화가 실제로 뜨는지 화면으로 확인한다.
