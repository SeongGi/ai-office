# 실제 오피스 고양이 대화 — 계획

설계는 `02-설계.md`에 있다. 커밋은 세 개로 나눈다. 시험은 이 서버기기 셸의 환경변수 영향을 빼고 돌린다.

```bash
T="env -u AGENT_FLOOR_URL -u AGENT_FLOOR_TOKEN -u AGENT_FLOOR_DEVICE"
```

## 커밋 1: 대사 모듈과 시험

- 새 파일: `shared/chatter.js`, `shared/chatter.d.ts`, `test/chatter.test.mjs`
- 내용: `cleanLine`, `topicOf`, `makeChat` (설계 1장), 시험 (설계 4장의 1~5)
- 검증: `$T node --test test/chatter.test.mjs`, `$T npm test` (기존 59개 + 새 시험 모두 통과)

## 커밋 2: 2D 드라이버와 World2D 연결

- 새 파일: `src/world2d/chatter2d.ts`
- 고칠 파일: `src/world2d/World2D.ts` (`sendLetter` 추출, `chatter.update`, `noteRealMessage`, `forget`, `clear`)
- 검증: `npm run typecheck`, `npm run build`, `$T npm test`

## 커밋 3: 화면 확인과 검증 문서

- 데모 모드(`?demo`)와 pages 빌드에서 쉬는 방 대화와 책상 대화가 보이는지 화면으로 확인한다.
- 실제 서버 화면에서는 로컬 서버(`node bin/agent-floor.mjs start`, 다른 포트)에 `emit`으로 가짜 팀 둘을 올려 확인한다. 운영 서버에는 이벤트를 보내지 않는다.
- 변이 검증: `shared/chatter.js`에 임시 변이를 넣어 시험이 실패하는지 보고 바로 원복한다.
- 결과를 `04-검증.md`에 적는다.
